# 📊 Accounts Receivable (AR) Dashboard – Power BI

## 📌 Project Overview

This project focuses on analyzing Accounts Receivable (AR) data using Microsoft Power BI. The dashboard transforms financial data into meaningful business insights through interactive visualizations, KPIs, and analytical reports.

The main objective is to help understand outstanding receivables, customer payment patterns, and ageing analysis to support better financial decision-making.

## 🎯 Project Objectives

- Analyze Accounts Receivable data.
- Monitor outstanding payments and receivables.
- Understand customer-wise payment patterns.
- Perform ageing analysis of outstanding invoices.
- Create interactive dashboards for better financial insights.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Data Analysis** – Exploring and understanding financial data.

## 📈 Dashboard Features

- Accounts Receivable overview.
- KPI tracking and financial summaries.
- Customer-wise receivables analysis.
- Invoice ageing analysis.
- Outstanding payment analysis.
- Interactive charts and visualizations.
- Multiple report pages with navigation.
- User-friendly dashboard design.

## 🔍 Key Learning Outcomes

Through this project, I gained practical experience in:
